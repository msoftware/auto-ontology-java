**MySQL-specific (these OVERRIDE the generic rules above)**
- `/` never truncates in MySQL: integer / integer returns a DECIMAL with, by default, 4 more decimal places (1 / 3 = 0.3333). Do NOT cast to make a division fractional; the generic 'cast to REAL before dividing' rule does not apply.
- Do NOT CAST a computed value (an aggregate, average, ratio or window result), or the column inside it, to DECIMAL(p, s), FLOAT, DOUBLE or REAL, and do not ROUND it, unless the question asks for a precision or for rounding: a cast changes the result's digits. Return computed values as MySQL produces them. The one exception: a ratio computed in a subquery or CTE keeps only 4 decimal places (1 / 1000000 = 0.0000), so if it is divided again later, cast its dividend to a DECIMAL with more scale.
- STDDEV(), STD() and VARIANCE() are the POPULATION statistics in MySQL (the same as STDDEV_POP() and VAR_POP()). Use the function the question names; use STDDEV_SAMP() or VAR_SAMP() only when it asks for a sample statistic.
